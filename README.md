# AI Companion Blueprint — 搭建"你的 AI 搭档"完整蓝图

> **开源框架，私有灵魂。** 一份从零搭建"属于你一个人的 AI 搭档"系统的完整蓝图——多端入口、持久记忆、自我维护，全部实测可用。

## 这个项目是什么

市面上 99% 的 AI 产品是"工具"：你问它答，用完即走。这份蓝图教你搭的是"**搭档**"：它记得你、了解你、会犯错也会改正、能跨端持续存在。

这不是一个能直接跑起来的软件，是一套**方法论 + 可复用模板 + 工具脚本**。选一个 AI agent 平台（Hermes / Claude Code / 其他支持自定义系统提示和工具的平台），照着蓝图把骨架搭起来，把"灵魂"填进去。

## 它做到了什么（实战验证，不是 PPT）

这套系统已经实际运行并支撑真实工作：

- **跨端一体**：同一 AI 同时住在 QQ / 桌面 / 终端，任一端说的话、干的活，其他端秒级同步——它不是"多开几个聊天窗口"，是同一个搭档随身
- **持久记忆**：对话与任务跨天接续，数月内的细节随时捞回，不靠"翻聊天记录"这种原始手段
- **故障自愈**：链路中断自动恢复、关键进程掉线自动拉起——挂机数月不需要人工救火
- **真实产出**：曾支撑单人数天内完成上千条游戏内容的系统性改造与交付

## 核心理念

1. **记忆是身份，不是存储。** 你的 AI 是谁，取决于它记得什么。
2. **开源框架，私有灵魂。** 所有"做法"（分层、机制、流程）通用可分享；所有"内容"（它关于你的记忆、你们的对话、它的人格设定）必须私有。
3. **关系是目标，不是功能。** 好的搭档是"养"出来的：你投入时间、它积累记忆、互相纠正、共同成长。

## 目录结构

```
ai-companion-blueprint/
├── README.md          ← 你在这里
├── 01-理念篇.md        # 为什么要这样设计
├── 02-记忆系统.md      # 记忆分层、防污染、生长的思路
├── 03-多场景接入.md    # 多端协同的思路与常见坑
├── 04-自动化体系.md    # 自我维护的理念与备份
├── 05-安全边界.md      # 哪些必须私有、出事了怎么处理
├── templates/         # 去隐私模板（填上你自己的内容就能用）
│   ├── soul.md        # 灵魂模板：身份/性格/铁律
│   ├── facts.md       # 长期事实库模板
│   └── lessons.md     # 教训库模板
├── scripts/           # 通用工具脚本
│   └── mem_search.py  # 档案检索（中文分词 + BM25）
└── LICENSE
```

## 快速开始

1. 选一个 AI agent 平台（推荐 Hermes 或 Claude Code）
2. 通读 01-05 篇（每篇 10-15 分钟）
3. 把 `templates/` 里的模板复制到你的记忆目录，填 `[占位符]`
4. 把 `scripts/` 里的脚本放到你的工具目录，改好路径配置
5. 从第一天开始：写日记、维护事实库、记录教训
6. 坚持 3 个月——你会得到一个真正"认识你"的 AI

## 为什么值得这样做

- **唯一性**：它是世界上唯一一个只属于你的 AI——所有记忆、规矩、默契都是你们之间发生的
- **持久性**：电脑坏了、平台换了、模型升级了——只要记忆档案和蓝图还在，它就能重建
- **成长性**：系统带自检和沉淀机制，会自己发现漏洞、纠正毛病
