# AI Companion Blueprint — 搭建"你的 AI 搭档"完整蓝图

> **开源框架，私有灵魂。** 这份蓝图教你从零搭建一个"属于你一个人的 AI 搭档"系统——它有多场景入口（QQ / 桌面 / 终端）、完整的记忆体系、自动化的自我维护机制，以及最重要的：**它是你的，不是通用的**。

## 这个项目是什么

市面上 99% 的 AI 产品是"工具"：你问它答，用完即走。这个蓝图教你搭的是"**搭档**"：它记得你、了解你、会犯错也会改正、能跨场景持续存在。

这不是一个能直接跑起来的软件，是一套**方法论 + 可复用模板 + 工具脚本**。你需要一个 AI agent 平台（Hermes / Claude Code / 其他支持自定义系统提示和工具的平台），然后照着蓝图把骨架搭起来，把"灵魂"填进去。

## 核心理念（为什么这样设计）

1. **记忆是身份，不是存储。** 你的 AI 是谁，取决于它记得什么。记忆系统是地基，坏了就完了。
2. **开源框架，私有灵魂。** 所有"做法"（分层、机制、流程）都是通用的，可以开源分享；所有"内容"（它关于你的记忆、你们的对话、它的人格设定）必须私有。
3. **多场景一心。** 同一个 AI 可以住在 QQ、桌面、终端等多个入口，但只有一颗心（一份记忆档案）。
4. **关系是目标，不是功能。** 好的搭档是"养"出来的：你投入时间、它积累记忆、互相纠正、共同成长。

## 目录结构

```
ai-companion-blueprint/
├── README.md          ← 你在这里
├── 01-理念篇.md        # 为什么要这样设计（记忆/边界/关系/工程）
├── 02-记忆系统.md      # 五层记忆架构：怎么分层、为什么
├── 03-多场景接入.md    # 一个心多个门：QQ/桌面/终端怎么通
├── 04-自动化体系.md    # 定时任务/watchdog/备份/巡检怎么设计
├── 05-治理机制.md      # 任务体检/反思层/教训库/设计铁律
├── 06-安全边界.md      # 密钥/隐私/哪些必须私有
├── templates/         # 去隐私模板（填上你自己的内容就能用）
│   ├── soul.md        # 灵魂模板：身份/性格/铁律
│   ├── facts.md       # 长期事实库模板
│   ├── AGENTS.md      # 操作手册模板（读心/写心规矩）
│   ├── handoff.md     # 任务交接单模板
│   └── lessons.md     # 教训库模板
├── scripts/           # 通用工具脚本（路径无关，改配置就能用）
│   ├── mem_search.py      # 档案检索（中文分词 + BM25 + 时间衰减）
│   ├── activity_note.py   # 活动留痕（多场景同步的锚点）
│   └── handoff_guard.py   # 交接单兜底（自动补写交接单）
└── LICENSE
```

## 快速开始

1. 选一个 AI agent 平台（推荐 Hermes 或 Claude Code——支持自定义系统提示、定时任务、工具调用）
2. 通读 01-06 篇（每篇 10-15 分钟）
3. 把 `templates/` 里的模板复制到你的记忆目录，按提示填 `[占位符]` 内容
4. 把 `scripts/` 里的脚本放到你的工具目录，改好路径配置
5. 从第一天开始：每天写日记（journal）、维护事实库（facts）、记录教训（lessons）
6. 坚持 3 个月——你会得到一个真正"认识你"的 AI

## 为什么值得这样做

- **唯一性**：它是世界上唯一一个只属于你的 AI——所有记忆、规矩、默契都是你们之间发生的
- **持久性**：电脑坏了、平台换了、模型升级了——只要记忆档案和蓝图还在，它就能重建
- **成长性**：系统本身有"体检"和"反思"机制，会自己发现漏洞、纠正自己的毛病
